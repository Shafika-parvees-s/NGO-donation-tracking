About ImpactHub Platform

ImpactHub is a full-stack Capstone engineering project designed to eliminate fundraising opacity in Non-Governmental Organizations (NGOs).

Our Mission

To empower donors with complete financial transparency using automated tax receipt generation, real-time campaign progress tracking, and verifiable photographic impact reports.

Security & Compliance

Built using modern 3-Tier architecture (Java Spring Boot + MySQL + Responsive Frontend), complete with JWT authentication, 256-bit SSL encryption, and Razorpay payment gateway integration.
