# Requirement Analysis

## 1. Project Overview

The NGO Donation & Impact Tracking Dashboard is a web-based platform that connects donors and NGOs in one system.

The platform allows users to view NGO campaigns, donate funds securely, and track the impact created by their donations.

NGOs can create campaigns, manage donations, and publish impact updates.

## 2. Users of the System

### Donor

A donor can:

- Register and login
- View NGO campaigns
- View campaign details
- Make donations
- View donation history
- Track campaign impact

### NGO

An NGO can:

- Register and login
- Create campaigns
- Manage campaigns
- View received donations
- Publish impact updates
- Track campaign progress

### Administrator

An administrator can:

- Manage users
- Verify NGOs
- Manage campaigns
- Monitor donations
- Monitor platform activities

## 3. Functional Requirements

The system should provide:

1. User registration and login
2. Role-based access
3. NGO management
4. Campaign creation and management
5. Campaign search and viewing
6. Online donation
7. Donation history
8. Payment status tracking
9. Impact report management
10. Dashboard and statistics
11. Admin management

## 4. Non-Functional Requirements

### Security

User passwords and sensitive information must be protected.

### Performance

The system should respond quickly to user requests.

### Availability

The website should be available to users whenever required.

### Scalability

The system should support an increasing number of users, NGOs and donations.

### Usability

The interface should be simple and easy to understand.

### Maintainability

The source code should be organized into separate frontend and backend modules.
