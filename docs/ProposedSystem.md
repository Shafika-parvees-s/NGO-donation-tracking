# Proposed System

## Overview

The proposed system is a web-based NGO Donation & Impact Tracking Dashboard developed using React, Spring Boot, and MySQL.

The platform allows NGOs to create fundraising campaigns, donors to make secure online donations, and administrators to monitor all activities.

## Features

- User Registration & Login
- NGO Profile Management
- Campaign Creation
- Online Donation
- Donation History
- Impact Tracking
- Admin Dashboard
- Reports & Analytics
- Secure Authentication
