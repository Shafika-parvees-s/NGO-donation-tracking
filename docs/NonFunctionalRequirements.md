# Non-Functional Requirements

## Security

The system should protect user accounts, passwords and donation information.

## Performance

The application should provide fast response for normal user operations.

## Reliability

Donation and transaction information should be stored correctly.

## Availability

The website should be accessible through the internet.

## Scalability

The system should support more users, NGOs and campaigns in the future.

## Usability

The website should have a simple and user-friendly interface.

## Maintainability

The frontend, backend and database should be organized separately.

## Compatibility

The website should work on modern browsers and different screen sizes.
